# Security policy

## Supported version

Shockbridge State Reliability is a pre-1.0 research codebase. Security fixes
are applied to the latest commit on `main`; earlier commits and local research
snapshots are retained for scientific provenance but are not maintained as
supported software releases.

## Reporting a vulnerability

Do not disclose a suspected vulnerability in a public issue. Use GitHub's
[private vulnerability reporting](https://github.com/rolffcoelho-bravo/shockbridge-state-reliability/security/advisories/new)
for the public repository. Include the affected path or commit, impact,
reproduction conditions, and a minimal proof of concept when safe to do so.

Please allow up to seven calendar days for an initial response. Confirmed
issues will be investigated under coordinated disclosure, with credit given
when requested and appropriate.

Methodological errors, data-provenance concerns, and scientific-reproducibility
questions that do not create a security risk may be reported through the
repository's public issue tracker. Never attach credentials, private datasets,
personal information, or restricted source artifacts to either channel.
