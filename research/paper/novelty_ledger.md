## Run 006 implication

The kill-gate result strengthens the potential value of N01 only if the redesign shows that propagating a continuous or uncertain state materially differs from forcing unstable hard regimes. It does not itself establish novelty. The closest prior work on continuous state-dependent local projections, factor-augmented event studies, and uncertainty propagation must be added before contribution language is drafted.

## Run 007 literature-audit implication

Continuous and polynomial state-dependent monetary-policy responses, smooth-transition local projections, principal-component factors, and classification-error corrections are established. The project therefore cannot claim novelty for using a continuous factor or a shock–state interaction. The defensible incremental question is narrower: whether a fully point-in-time latent state with recorded first-stage uncertainty changes finite-dose euro-area event-transmission conclusions under a prospective evidence gate. Gonçalves et al. (2024) makes the finite-dose estimand and endogenous-state problem a mandatory design constraint; David et al. (2026) is a current, non-peer-reviewed warning against interpreting a misspecified linear interaction as a causal state-response function.

## Run 007 refinement-implementation implication

The quadratic tensor surface and coherent PCA-emission challenger are benchmark architecture, not candidate novelty. N01 remains conditional on propagating the filtered factor distribution into downstream contrasts and re-estimating the first stage in valid uncertainty calculations. A point-estimate-only state analysis would not support the stated contribution even if its interaction terms were statistically significant.

## Run 008 design implication

Principal-angle diagnostics, Procrustes rotation, fixed-loading factors, multifactor PCA, and economic subspace regularization are established tools. Nakagawa, Kato and Imamura (2026) is especially close prior art for stabilizing rolling PCA toward an economic exposure subspace. Run 008 is therefore a validation redesign, not a method-novelty claim. Its potential paper value is disciplined negative-result recovery: distinguishing failure of an ordered first component from failure of the underlying point-in-time factor space while preserving an outcome firewall and refusing post-hoc promotion.

Run 008 subsequently rejected the required two-dimensional subspace and the fixed scalar under their prospective gates. This strengthens the evidence for a measurement-reliability contribution but does not, by itself, establish novelty. Any paper claim must distinguish the established geometry from the project's contribution: an auditable point-in-time validation sequence showing that favorable predictive density can coexist with economically consequential history-window instability.

## Run 009 design implication

Eigengap diagnostics, subspace perturbation bounds, loading-break tests, change-point methods, and decompositions of factor-variance versus loading instability are established. Run 009 cannot claim these tools as novel, and the four-feature panel does not support high-dimensional factor-break asymptotics. Its potential contribution is narrower: a prospectively frozen, outcome-blind forensic audit of why a real-time state measurement fails despite favorable predictive density, with explicit refusal to use the diagnosis for post-result model rescue.

Run 009 supplies evidence for that narrow contribution: failure is pervasive across three window lengths, occurs in long continuous episodes, is not concentrated in the prespecified weak-eigengap condition, and is dominated descriptively by off-diagonal comovement drift. This remains a candidate contribution rather than a novelty claim. A paper must compare the audit sequence with the closest real-time factor-stability and model-risk literature and should test whether the result changes under an explicitly labeled revised-data or alternative-measurement benchmark.

## Run 010 design implication

Real-time versus revised-data comparisons are established and are not a novelty claim. Run 010 can add scientific value only through its controlled contrast: it freezes the point-in-time observation-period and missingness mask, changes the macro vintage, reuses the Run 009 geometry contract, and refuses to treat an ex-post stable result as a decision-time model rescue. The latest ECB RTD vintage may include composition, benchmark, seasonal-adjustment, or rebasing changes, so the paper must call it a matched-period latest-vintage sensitivity rather than a pure revision experiment. The candidate contribution remains the auditable validation sequence and its negative-evidence discipline, not the comparison itself.

Run 010 supplies the required empirical sensitivity: all three full-panel failures, all 15 deletion-window classifications, and the persistent episode structure survive the matched-period latest vintage. This strengthens the candidate value of the validation sequence but does not make vintage comparison, PCA geometry, or block resampling novel. The next novelty-critical task is a focused prior-art audit of real-time factor stability, vintage sensitivity, and disciplined negative-result/model-risk workflows; contribution language remains provisional until that audit and independent reproduction are complete.

## Run 011 positioning implication

The focused audit and exact clean reproduction complete the two immediate
credibility gates left by Run 010. Euro-area real-time database construction,
vintage comparison, factor-loading instability, real-time factor forecasting,
forecast-breakdown analysis, model-confidence sets, principal-angle geometry,
and block resampling are established. None may be claimed as a new method.

The defensible candidate contribution is narrower: a prospectively frozen,
artifact-level validation sequence in which favorable predictive density does
not override unstable economic geometry; the negative measurement decision
survives a controlled latest-vintage sensitivity; and the downstream
transmission study is terminated without outcome-driven model rescue. This is
an application and scientific-governance contribution under test. It is not yet
a novelty claim and remains conditional on manuscript-level synthesis,
cross-platform reproduction, and external review.

## Run 012 release implication

Dependency locks, secret scanning, portable inventories, public CI, and a
claim-controlled manuscript architecture increase credibility and reuse value;
they do not add econometric novelty. Same-host exact locked reproduction removes
one implementation-specific concern but does not establish external validity or
cross-platform generality. The scientific contribution remains the Run 007–010
validation sequence and negative measurement decision, subject to external
review.

## Claim discipline

- “Novel” is prohibited in the manuscript title, abstract, and contribution list until the literature ledger documents the closest methods and the incremental difference.
- A software innovation is not automatically an econometric contribution.
- A null or failed benchmark remains part of the methodological evidence.
- Novelty priority is N01 and N02; N03–N05 support them but should not inflate the contribution count.
